A database-first airline baggage planning tool with Quick Check, Full Trip, reverse airline search and shared bag-size planning.

== Features ==
* Quick Check for one bag and one airline
* Full Trip mode with up to 6 bags and 10 flights
* Personal item, carry-on and checked-bag support
* Marketing and operating airline fields
* Ticket allowance parser for common lines such as 1PC 23KG
* Reverse search: which airlines accept this bag?
* Best Shared Size across selected airlines
* 250 airline profiles with transparent coverage tiers
* 7,883 airport search records
* Official airline source links
* Saved anonymous result links
* Controlled two-page printable report
* No AI dependency and no paid API
* Shortcode: [voyasee_bag_checker]

== Accuracy ==
BagFit is a planning assistant. Airline allowances can vary by fare, route, date, aircraft, operating carrier, status and purchase method. The issued ticket and official airline page remain authoritative.

The bundled airline directory has three tiers: deeply reviewed rule sets, core source-linked starter rules and directory-only official links. Directory-only profiles cannot create an unconditional numerical pass.

== Upgrade Notice ==
Version 7.0 automatically upgrades the bundled data while preserving airline profiles marked as administrator-customised.
