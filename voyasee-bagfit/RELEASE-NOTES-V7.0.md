# Voyasee BagFit 7.0.0

## Main upgrade

BagFit 7.0 is a database-first rebuild with four public modes:

1. Quick Check — one bag and one airline
2. Full Trip — multiple bags, travellers and flights
3. Which Airlines Fit? — reverse comparison against stored rules
4. Best Shared Size — one bag size across selected airlines

## New public features

- Up to 6 bags and 10 flights
- Per-bag owners and bag categories
- One-ticket, separate-ticket and self-transfer context
- Marketing and operating airline selection
- Ticket allowance parser for common baggage lines
- Global airport autocomplete
- Multi-bag flight matrix
- Practical oversized-bag guidance
- Infographic decision board
- Contextual Voyasee tool handoffs
- Expanded permanent footer using approved Voyasee links

## Data coverage

- 250 airline profiles total
- 34 deeply reviewed profiles
- 125 core source-linked profiles
- 91 directory-only profiles
- 7,883 airport search records

The directory count is not presented as 250 fully verified numerical rule sets. Directory-only profiles link to official airline pages and require confirmation.

## No external decision API

No AI or paid baggage API is required. All calculations use local structured data and values confirmed by the traveller.
